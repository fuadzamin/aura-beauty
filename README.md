# Aura Beauty Clinic & POS Application

A modern, full-featured web application for **Aura Beauty Clinic**, built with **React**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**. It features a luxury customer-facing clinic portal and a comprehensive **Point of Sale (POS) & Admin Dashboard** designed for clinic management, reservations, and skincare add-on checkout.

---

## ✨ Features

### 🌸 Customer Portal
- **Treatment Showcase**: Explore medical aesthetics, laser treatments, anti-aging therapies, and facial care with detailed duration and pricing.
- **Doctor Directory**: View board-certified dermatologists, their credentials, schedules, and clinical specialties.
- **Online Reservation**: Seamlessly book consultation & treatment slots with branch and doctor selection.
- **Skincare Store**: Browse medical-grade skincare products by category (Serum, Cleanser, Sunscreen, Cream) with variant sizes and instant search.

### 💳 POS (Point of Sale) Kasir
- **Compact One-Page POS Layout**: Clean, high-density dashboard requiring zero scrolling.
- **Integrated Reservation Selection**: Fast search bar for finding active patient bookings.
- **Medical Treatment & Add-On Skincare Catalog**: Minimalist text-based itemized selection with real-time stock indicators.
- **Instant Checkout & Cash Calculator**: Supports QRIS, Credit/Debit, Bank Transfer, and Cash payment with automatic change calculation.
- **Printable Thermal Receipts**: Professional printable invoice receipt modal for clinic patients.

### 📊 Admin Management
- **Analytics Overview**: Track daily revenue, total bookings, inventory metrics, and recent transactions.
- **Reservation Lifecycle Management**: Confirm, update, or convert reservations directly into POS invoices.
- **Inventory & Stock Control**: Real-time stock adjustment and variant management.
- **Transaction History**: Comprehensive purchase logs with customer contact details and payment methods.

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js (version 18 or higher) installed on your system.

```bash
node -v
npm -v
```

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/aura-beauty-clinic.git
   cd aura-beauty-clinic
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**:
   Navigate to `http://localhost:3000` to view the application.

---

## 📜 Scripts

- `npm run dev` - Launches the Vite development server on port 3000.
- `npm run build` - Builds the production bundle in the `dist` folder.
- `npm run lint` - Runs TypeScript checks and code linting.
- `npm run preview` - Previews the production build locally.
